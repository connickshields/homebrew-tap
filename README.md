# homebrew-tap

Homebrew tap for [Sightglass](https://github.com/connickshields/sightglass), a macOS menu bar app for watching long-running jobs.

```sh
brew install --cask connickshields/tap/sightglass
```

`Casks/sightglass.rb` is generated by Sightglass's release workflow from `packaging/sightglass.rb.tmpl` in that repo. Changes made here are overwritten by the next release, so edit the template instead.
